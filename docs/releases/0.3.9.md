# 0.3.9 - Menu bar exceptions and middle scrolling fixes

You can now open the mxlt-utils menu while using an app and choose **Keep [app] running** or **Disable middle scrolling in [app]**. Both actions use the exception lists in Settings, where you can remove an app later.

## Middle scrolling

- If monitoring fails, turning middle scrolling off clears its warning. Turning it back on checks access and makes a fresh start attempt.
- Speed, dead zone, direction, and smoothing changes take effect on the next middle press. You can adjust them while monitoring stays active.
- A system overlay on another display or behind the original window no longer interrupts a gesture. Overlays covering the point where you pressed still require verification.
