# 0.3.8 — Faster scrolling, including with OBS

Middle scrolling now gets much faster far from the anchor, and keeps working when OBS Display Capture is active.

## What's improved

- **Move farther to scroll faster.** Extra acceleration builds smoothly beyond 200 points outside the dead zone. The maximum speed is six times higher, while nearby movement keeps its precise control. Release, Escape and returning to the anchor still stop scrolling immediately.
- **Scroll while capturing your display.** macOS can expose the captured cursor as a window. mxlt-utils now recognizes that verified system cursor without mistaking it for a window blocking your scroll target. Real covering windows still cancel the gesture.
- **Keep your settings.** Existing speed, smoothing, feature choices and application exceptions carry over.

## Download & install

Download [mxlt-utils-0.3.8-macos-arm64.dmg](https://github.com/Mxlted/mxlt-utils/releases/download/v0.3.8/mxlt-utils-0.3.8-macos-arm64.dmg), open it, and drag **mxlt-utils** into **Applications**. Quit an older running copy before replacing it, then launch the updated app.

Requires **macOS 14 or later on Apple silicon**. The app and DMG are Developer ID signed, notarized, and stapled. [SHA256SUMS.txt](https://github.com/Mxlted/mxlt-utils/releases/download/v0.3.8/SHA256SUMS.txt) covers the final DMG. Version **0.3.8**, build **7**.

## Validation & preview limits

All **214 XCTest cases** and exact-commit CI pass. Synthetic native checks with OBS Display Capture active verify fast and normal scrolling, paired middle clicks, Escape, nested scrolling and target pinning. The fast-scroll check measures delivery above the previous speed limit and verifies stopping without a leaked click. Ordinary-wheel passthrough was checked separately with another utility's wheel smoothing stopped.

Release validation includes signatures, accepted notarization, stapled tickets and the app copied from the DMG. Physical-mouse feel, older macOS versions and other capture applications remain unverified; this is not a claim of matching an exact Windows scrolling algorithm. See the [testing record](https://github.com/Mxlted/mxlt-utils/blob/v0.3.8/docs/TESTING.md).
