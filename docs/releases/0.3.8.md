# 0.3.8 - Faster scrolling and OBS capture fix

Middle scrolling now reaches higher speeds farther from the starting point. This release also fixes gestures canceling while OBS Display Capture is active.

## Changed

- Added stronger acceleration beyond 200 points outside the center dead zone. The maximum scroll speed is now six times higher, while movement near the center retains its fine control. Release, Escape, and returning to the center still stop scrolling immediately.

## Fixed

- Fixed middle scrolling and short middle clicks canceling when OBS Display Capture exposes the macOS cursor as a window. The system cursor is no longer mistaken for a window covering the scroll target. Actual covering windows still cancel the gesture.
