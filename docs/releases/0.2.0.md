# 0.2.0 - Smooth middle scrolling

Middle scrolling now eases changes in speed, with an option to keep the original direct response.

## Changes

- Added **Smooth scrolling**, enabled by default. Turn it off in Middle scrolling settings if you prefer a direct response. Your choice is saved across relaunches.
- Increased the scroll timer to 60 Hz and preserved small movements at low speeds.
- Updated the README and project overview to make the available utilities and setup easier to find.

Returning to the center, releasing the button, or pressing Escape still stops scrolling immediately. Ordinary wheel and trackpad scrolling are unchanged.
