# 0.2.0 — Smoother scrolling, room to grow

mxlt-utils is a growing collection of small, native Mac utilities. This preview adds smooth middle scrolling and updates the project presentation to reflect a toolkit that grows with everyday needs.

## What's new

- **Smooth middle scrolling.** Speed changes ease in while you hold the mouse wheel. Returning to the center, releasing, or canceling still stops immediately.
- **Your preferred feel.** Smooth scrolling is on by default. Turn it off in Middle scrolling settings for a direct response; your choice is remembered across relaunches.
- **More frequent output.** The scroll timer now targets 60 Hz, with fractional movement preserved at low speeds. Every event still requires a valid original target.
- **A clearer home for the toolkit.** The README and About section introduce the current utilities as a starting point, with room for new tools as needs arise.

CallQuits remains independently enabled, with its existing close checks and exceptions. Ordinary wheel and trackpad input are unchanged.

## Download & install

Download [mxlt-utils-0.2.0-macos-arm64.dmg](https://github.com/Mxlted/mxlt-utils/releases/download/v0.2.0/mxlt-utils-0.2.0-macos-arm64.dmg), open it, and drag **mxlt-utils** into **Applications**. Quit an older running copy before replacing it, then open the updated app. Existing settings are retained.

Requires **macOS 14 or later on Apple silicon**. Enable the utilities you want and allow Accessibility when requested. Use one quit monitor at a time. Updates are installed manually from GitHub Releases.

The app and DMG are Developer ID signed, notarized, and stapled. [SHA256SUMS.txt](https://github.com/Mxlted/mxlt-utils/releases/download/v0.2.0/SHA256SUMS.txt) covers the final DMG. Version **0.2.0**, build **2**.

## Validation & preview limits

- All **165 XCTest cases** pass, covering quit safeguards, scroll motion and cancellation, settings, and native event routing.
- Synthetic native input through the signed candidate passes view-level middle clicks, ordinary wheel passthrough, continuous and nested scrolling, original-window pinning, dead-zone/release/Escape stops, pause/disable cleanup, and repeated feature toggles.
- Disposable quit fixtures pass graceful last-window quit, canceled save prompts, replacement windows, a minimized remaining window, native tab close, and Command-W.
- The new Smooth scrolling control was inspected in dark appearance; a separate native scroll check also passed with smoothing disabled.

These checks do not establish physical-mouse feel or a measured 60 Hz delivery rate. Browser coverage recorded for 0.1.0 has not been repeated for this version. Broader app compatibility, older macOS runtimes, Intel, mixed-scale displays, sleep/lock, midgesture permission revocation, and separate-account installation still need verification. See the [testing record](https://github.com/Mxlted/mxlt-utils/blob/v0.2.0/docs/TESTING.md) for details.

Apps can impose their own axis locking or handle middle-drag differently. Exclude incompatible apps in settings. Scrolling cancels when its original window moves, becomes covered or hidden, closes, or cannot be verified; it does not redirect to another window.
