# 0.3.7 — Find mxlt-utils in Apps

Fixes mxlt-utils missing from Apple's Apps launcher after installation. macOS now correctly identifies it as an Apple-silicon Mac app.

## What's fixed

- **Visible in Apps.** The bundle now explicitly declares its macOS platform. Without that metadata, macOS could incorrectly classify the app as an iOS app.
- **Same menu-bar behavior.** The app still stays out of the running Dock and keeps your existing settings. Quit on Close and Middle scrolling behavior are unchanged.

## Download & install

Download [mxlt-utils-0.3.7-macos-arm64.dmg](https://github.com/Mxlted/mxlt-utils/releases/download/v0.3.7/mxlt-utils-0.3.7-macos-arm64.dmg), open it, and drag **mxlt-utils** into **Applications**. Quit an older running copy before replacing it, then launch the updated app.

Requires **macOS 14 or later on Apple silicon**. The app and DMG are Developer ID signed, notarized, and stapled. [SHA256SUMS.txt](https://github.com/Mxlted/mxlt-utils/releases/download/v0.3.7/SHA256SUMS.txt) covers the final DMG. Version **0.3.7**, build **6**.

## Validation & preview limits

The installed corrected preview changed from an iOS classification to Apple Silicon in System Information, and the user confirmed that it appeared in Apps. All **210 XCTest cases** and exact-commit CI pass; release validation also checks signatures, notarization, stapled tickets, and the app copied from the DMG.

This update changes bundle metadata, not input handling. Existing app-compatibility and physical-input coverage limits still apply; see the [testing record](https://github.com/Mxlted/mxlt-utils/blob/v0.3.7/docs/TESTING.md).
