# 0.3.6 — Quit on Close, including startup Cancel

Canceling a supported startup file chooser can now quit the app completely, so it no longer lingers in the Dock when no windows remain. CallQuits is now named **Quit on Close** in settings and the menu.

## What's improved

- **Quit after Cancel.** Handles matching macOS Open panels across eligible apps, including TextEdit, Preview, and QuickTime Player. Support follows the verified system panel rather than an app-name list.
- **Middle-click tab closing.** Recognizes supported native tab closes, including short clicks delivered by Middle scrolling. The app quits only when the final window actually closes; an empty window still counts as open.
- **Keep unfinished work safe.** Remaining documents, save prompts, replacement windows, and uncertain window state prevent quitting. Existing exceptions and preferences are retained.

## Download & install

Download [mxlt-utils-0.3.6-macos-arm64.dmg](https://github.com/Mxlted/mxlt-utils/releases/download/v0.3.6/mxlt-utils-0.3.6-macos-arm64.dmg), open it, and drag **mxlt-utils** into **Applications**. Quit an older running copy before replacing it, then launch the updated app.

Requires **macOS 14 or later on Apple silicon**. Enable the utilities you want and allow Accessibility when requested. Updates are installed manually from GitHub Releases.

The app and DMG are Developer ID signed, notarized, and stapled. [SHA256SUMS.txt](https://github.com/Mxlted/mxlt-utils/releases/download/v0.3.6/SHA256SUMS.txt) covers the final DMG. Version **0.3.6**, build **5**.

## Validation & preview limits

- All **210 XCTest cases** pass, covering quit safeguards, native identity, dialog/tab recognition, scrolling, cancellation, settings, and permission recovery.
- Development previews passed scoped synthetic Cancel clicks with actual process exit in TextEdit, Preview, and QuickTime Player. Separate remaining-document and Save-cancel checks preserved the app and document. The user also reported that the TextEdit fix appears to work.
- Other apps using the same system panel are candidates, not confirmed compatible apps. Custom choosers and different Accessibility layouts may remain unsupported. Very fast clicks can be missed safely, leaving the app open.
- Broad browser middle-click integration, physical mouse coverage, minimized/other-Space survivors for the new Cancel path, and older macOS runtime checks remain incomplete. See the [testing record](https://github.com/Mxlted/mxlt-utils/blob/v0.3.6/docs/TESTING.md) for methods and remaining checks.

Release validation includes exact-commit CI, signatures, both notarizations, stapled tickets, and verification of the app copied from the final DMG. No new app launches or input injection are performed during release preparation.
