# 0.3.6 - Quit after closing a startup dialog

Quit on Close now handles Cancel in supported startup file choosers, including those in TextEdit, Preview, and QuickTime Player.

## Changes

- Canceling an app's only supported startup Open dialog now requests a normal quit after the dialog closes. Existing documents, save prompts, replacement windows, and unreadable window state keep the app open.
- Added support for middle-click closing of native tabs, including short clicks passed through by Middle scrolling. The app quits only when the final window closes; an empty window still counts as open.
- Renamed **CallQuits** to **Quit on Close** in settings and the menu. Existing preferences and app exceptions carry over.
