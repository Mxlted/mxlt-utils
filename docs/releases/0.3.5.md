# 0.3.5 — Better middle clicks and safer permission changes

This preview fixes middle clicks in bookmark folders, makes scrolling respond more strongly to distance, and addresses lost mouse input when an enabled Accessibility entry is removed.

## What's improved

- **Bookmark-folder clicks.** Short middle clicks can open bookmarks from folder menus and other elevated app windows. Clicks remain tied to the original window, so dismissed or covered menus cannot redirect them.
- **Distance-controlled scrolling.** Move a little for fine control, or farther from the anchor to scroll faster. Moving closer slows scrolling, and release or Escape stops it immediately.
- **Safer permission removal.** Middle scrolling checks whether macOS still permits input filtering, including when its Accessibility status is stale after deletion. Failed checks detach monitoring; timeout recovery and manual retry require fresh access checks.
- **Clearer recovery.** Settings shows when input access is unavailable. Restore Accessibility access, then click **Retry monitoring**. Feature choices and scroll settings are retained.

## Download & install

Download [mxlt-utils-0.3.5-macos-arm64.dmg](https://github.com/Mxlted/mxlt-utils/releases/download/v0.3.5/mxlt-utils-0.3.5-macos-arm64.dmg), open it, and drag **mxlt-utils** into **Applications**. Quit an older running copy before replacing it, then launch the updated app.

Requires **macOS 14 or later on Apple silicon**. Enable the utilities you want and allow Accessibility when requested. Updates are installed manually from GitHub Releases.

The app and DMG are Developer ID signed, notarized, and stapled. [SHA256SUMS.txt](https://github.com/Mxlted/mxlt-utils/releases/download/v0.3.5/SHA256SUMS.txt) covers the final DMG. Version **0.3.5**, build **4**.

## Validation & preview limits

- All **190 XCTest cases** pass, covering quit safeguards, click routing, scrolling, cancellation, settings, and permission/recovery races with injected checks.
- The user confirmed that the mouse restriction after deleting an enabled Accessibility entry appears resolved in the development preview. Broader permission scenarios and device coverage remain incomplete.
- Release builds, exact-commit CI, signatures, notarization, stapled tickets, and the packaged app are verified. No new app launches or input injection were performed during release preparation.

Polling intervals do not guarantee a fixed recovery deadline. Browser popup behavior, mixed displays, older macOS versions, and other input utilities still need broader testing. See the [testing record](https://github.com/Mxlted/mxlt-utils/blob/v0.3.5/docs/TESTING.md) for the evidence and remaining limits.
