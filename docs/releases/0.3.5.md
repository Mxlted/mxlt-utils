# 0.3.5 - Middle-click and Accessibility fixes

Fixes dropped middle clicks in bookmark menus and addresses mouse input becoming restricted after an enabled Accessibility entry is deleted.

## Fixed

- Short middle clicks now work in bookmark-folder menus and other raised app windows. Dismissing or covering a menu cancels the click instead of sending it to the window underneath.
- Middle scrolling now checks whether input access actually works, including when macOS still reports access as allowed after the Accessibility entry has been deleted. A failed check stops input monitoring.
- Settings now shows when input access is unavailable. Restore Accessibility access, then click **Retry monitoring** to resume.

## Changed

- Scroll speed now increases progressively with distance from the starting point, giving finer control nearby and more speed farther away. Release and Escape still stop immediately.
