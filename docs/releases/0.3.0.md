# 0.3.0 - Scroll timing and a new icon

This release updates middle-scroll timing, expands the speed control, and introduces the Fold app icon.

## Changes

- Smooth scrolling now schedules updates with the display where the gesture started, including displays with higher refresh rates.
- Scroll timing accounts for skipped frames without allowing a long delay to produce a large jump.
- The scroll-speed slider now runs from 0.2× to 10×. Smoothing keeps a fixed response with a simple on/off switch.
- Added the Fold icon: a mint geometric mark on charcoal.

Release, Escape, and returning to the center still stop scrolling immediately.
