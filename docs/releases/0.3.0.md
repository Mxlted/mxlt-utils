# 0.3.0 — A fresh icon and smoother scrolling

This preview brings the new Fold icon, more responsive middle-scroll timing, and a simpler speed control.

## What's new

- **A new look.** Fold pairs a mint geometric mark with a charcoal background across the app icon and project artwork.
- **Scrolling that follows your display.** Smooth mode now requests the original display's refresh rate, including higher-refresh screens. Timing accounts for skipped validation frames while keeping delayed movement bounded.
- **More speed, less clutter.** Scroll speed now reaches 10×, with a continuous slider and a clear numeric readout. Smooth scrolling keeps its default response and a simple on/off switch.

Release, Escape, and returning to the center still stop scrolling immediately. Existing settings are retained. Ordinary wheel and trackpad input and CallQuits behavior are unchanged.

## Download & install

Download [mxlt-utils-0.3.0-macos-arm64.dmg](https://github.com/Mxlted/mxlt-utils/releases/download/v0.3.0/mxlt-utils-0.3.0-macos-arm64.dmg), open it, and drag **mxlt-utils** into **Applications**. Quit an older running copy before replacing it, then launch the updated app.

Requires **macOS 14 or later on Apple silicon**. Enable the utilities you want and allow Accessibility when requested. Updates are installed manually from GitHub Releases.

The app and DMG are Developer ID signed, notarized, and stapled. [SHA256SUMS.txt](https://github.com/Mxlted/mxlt-utils/releases/download/v0.3.0/SHA256SUMS.txt) covers the final DMG. Version **0.3.0**, build **3**.

## Validation & preview limits

- All **173 XCTest cases** pass, covering quit safeguards, scroll motion, timing, cancellation, settings, and native event construction and routing policies.
- Release builds, icon representations, signatures, notarization, stapled tickets, and the packaged app are checked without launching the app.
- Manual app launches and mouse testing are handled separately. No new running-app synthetic input or physical mouse checks are claimed for this version; earlier fixture results remain documented as historical evidence.

Display scheduling does not guarantee a measured frame rate or perceived smoothness in every app. Mixed displays, older macOS runtimes, and broader app compatibility still need verification. See the [testing record](https://github.com/Mxlted/mxlt-utils/blob/v0.3.0/docs/TESTING.md) for the evidence and remaining limits.
