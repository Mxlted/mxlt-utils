# 0.1.0 - First preview

The first release of mxlt-utils brings two optional utilities to the Mac menu bar: CallQuits and Middle scrolling.

## Included

- **CallQuits** quits an app after you close its last window. Supports the red close button, native tab closing, and Command-W, with exceptions for apps you want to keep running. Save prompts, canceled closes, and remaining windows keep the app open.
- **Middle scrolling** lets you hold the mouse wheel and move to scroll vertically, horizontally, or diagonally. Move farther from the starting point to scroll faster. Return to the center to pause, or release the button or press Escape to stop. Short middle clicks are preserved when the original target is still available.
- Separate feature switches, a menu-bar pause control, app exclusions, and optional launch at login. Both features start off.
- Native SwiftUI and AppKit settings. No accounts, telemetry, or third-party runtime dependencies.

If you already use standalone CallQuits, enable quitting in only one app. The two apps keep separate preferences.
